# Proyecto Django con Docker

Este proyecto utiliza **Docker** y **docker-compose** para levantar la aplicación Django junto con Redis de forma rápida y segura.

---

## Requisitos
- Docker >= 24.0  
- Docker Compose >= 2.0  
- Git  

---

## Ejecución de la aplicación

### Construir e iniciar los contenedores
Desde la raíz del proyecto, ejecutar:

```bash
docker compose up --build
